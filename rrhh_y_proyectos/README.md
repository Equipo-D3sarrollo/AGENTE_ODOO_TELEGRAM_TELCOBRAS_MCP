# 👥 Categoría: RRHH y Proyectos - Telcobras S.A.S.

## 📖 ¿Qué es y para qué se usa esta categoría?
La categoría **RRHH y Proyectos** concentra toda la documentación relacionada con la gestión del talento humano, procesos de evaluación de desempeño, organización del equipo de desarrollo y directrices de identidad corporativa.

**¿Para qué se usa?**
* **Gestión del Talento Humano:** Estandariza los procesos de evaluación de desempeño, su configuración y la administración de fichas de empleados.
* **Organización y Desarrollo:** Documenta la estructura del equipo de desarrollo, asignaciones y flujos de trabajo sobre Odoo.
* **Identidad Corporativa:** Proporciona las directrices oficiales del manual de marca para mantener la coherencia visual e institucional de la empresa.

## 🚀 Guía: ¿Cómo agregar un nuevo manual correctamente?

Para mantener la base de conocimiento organizada y funcional tanto para el equipo como para el agente de IA (Make.com), siga estrictamente estos 4 pasos al crear un nuevo manual en esta categoría.

### 1. Naming y Ubicación del Archivo
* **Ruta:** Guarde el nuevo archivo dentro de la carpeta `rrhh_y_proyectos/`.
* **Nomenclatura:** Utilice un número secuencial de dos dígitos seguido de un nombre descriptivo en minúsculas separado por guiones bajos (ej. `07_politica_bienestar.md`).

### 2. Estructura y Estándar de Contenido (Semantic Markdown)
Todo manual nuevo debe incluir obligatoriamente los metadatos de contexto al inicio:
```markdown
<!-- Path: rrhh_y_proyectos/07_politica_bienestar.md -->

# Título Descriptivo del Documento

**Módulo / Área:** RRHH y Proyectos / Talento Humano  
**Rol Requerido:** [Roles con acceso]  
**Empresa / Proyecto:** Telcobras S.A.S.  
**Cuándo usar este documento:** [Propósito breve del manual]

---

## 1. Sección Principal
...
```

### 3. Reglas de mantenimiento y organización
* Mantener nombres de archivo consistentes con la nomenclatura del área.
* Evitar duplicar documentos que cumplen la misma función dentro de RRHH o proyectos.
* Asegurar que cada manual refleje una versión definitiva y actualizada.

### 4. Validación final
* Revisar que el documento corresponda a la categoría `rrhh_y_proyectos/`.
* Confirmar que su nombre, contenido y numeración sean consistentes.
* Incluirlo en este índice para mantener la trazabilidad documental del área.
