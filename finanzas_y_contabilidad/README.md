# 📊 Categoría: Finanzas y Contabilidad - Telcobras S.A.S.

## 📖 ¿Qué es y para qué se usa esta categoría?
La categoría **Finanzas y Contabilidad** concentra toda la documentación contable, fiscal, financiera y tributaria de Telcobras S.A.S. y su operación asociada en Xpertic.

**¿Para qué se usa?**
* **Gestión Tributaria y DIAN:** Estandariza los procesos de facturación electrónica, documentos soporte y notas crédito/débito conforme a la normativa vigente en Colombia.
* **Control Operativo Financiero:** Regula el manejo, topes y legalización de fondos como caja menor.
* **Automatización y Procesos:** Documenta la integración de agentes de IA para optimizar la causación contable y el procesamiento de documentos financieros.

## 🚀 Guía: ¿Cómo agregar un nuevo manual correctamente?

Para mantener la base de conocimiento organizada y funcional tanto para el equipo como para el agente de IA (Make.com), siga estrictamente estos 4 pasos al crear un nuevo manual en esta categoría.

### 1. Naming y Ubicación del Archivo
* **Ruta:** Guarde el nuevo archivo dentro de la carpeta `finanzas_y_contabilidad/`.
* **Nomenclatura:** Utilice un número secuencial de dos dígitos seguido de un nombre descriptivo en minúsculas separado por guiones bajos (ej. `08_politica_retenciones.md`).

### 2. Estructura y Estándar de Contenido (Semantic Markdown)
Todo manual nuevo debe incluir obligatoriamente los metadatos de contexto al inicio:
```markdown

**Cuándo usar este documento:** [Propósito breve del manual]

---

## 1. Sección Principal
...
```

### 3. Reglas de cumplimiento tributario y controlar versiones
* Mantener precisión documental y alineación con la normativa aplicable.
* Vincular documentos con procesos reales de operación financiera.
* Registrar cambios importantes en políticas, topes o parametrización.

### 4. Validación y mantenimiento
* Verificar que el archivo pertenezca a la categoría `finanzas_y_contabilidad/`.
* Confirmar que el número y el nombre del documento correspondan correctamente a su contenido.
* Actualizar este índice para reflejar la versión final publicada.
