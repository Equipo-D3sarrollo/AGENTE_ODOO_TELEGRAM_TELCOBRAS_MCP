# 🏢 Base de Conocimiento y Arquitectura Agente IA - Telcobras S.A.S.

> **Creado por:** Cristian Bedoya 👨‍💻  
> **Propósito:** Repositorio oficial centralizado de Procedimientos Operativos Estándar (SOP) en Markdown Semántico y documentación técnica para la integración del Agente de IA de Operaciones y Soporte en Odoo, Telegram y Make.com.

---

## 📋 ¿Qué es este repositorio y para qué sirve?

Este repositorio funciona como el **cerebro documental y la fuente única de verdad** para el Agente de Inteligencia Artificial de Telcobras S.A.S. Contiene guías modulares estructuradas que permiten responder consultas operativas, comerciales, financieras y técnicas con base documental actualizada y trazable.

---

## 📁 Estructura del Repositorio

La documentación está organizada por áreas operativas y técnicas en las siguientes carpetas:

* **`arquitectura_y_sistemas/`** ⚙️ — Estándares técnicos, arquitectura de integración MCP y conexiones con Make.com y GitHub.
* **`comercial/`** 💼 — Portafolio de servicios, propuestas comerciales, oferta de valor y posicionamiento corporativo.
* **`compras_y_pagos/`** 💳 — Procesos de aprobación de pagos por Telegram y control de cuentas por pagar.
* **`finanzas_y_contabilidad/`** 📊 — Documentos soporte electrónico, manejo de caja menor multiempresa (Xpertic) y agentes de causación de facturas.
* **`inventario_y_logistica/`** 📦 — Control de flota vehicular, nomenclatura y creación estandarizada de productos.
* **`rrhh_y_proyectos/`** 👥 — Evaluaciones de desempeño y manuales de puesta en marcha para equipos técnicos en Odoo.

---

## ⚙️ ¿Cómo funciona y cómo se usa?

1. **Lectura en Tiempo Real (*Raw URLs*):** El agente implementa el protocolo MCP y utiliza la herramienta `fetch_generic_url_content` en Make.com para leer directamente el contenido en texto plano desde los archivos Markdown del repositorio.
2. **Actualización Inmediata:** Cualquier cambio aprobado en los archivos Markdown se refleja automáticamente en las respuestas del agente en producción, sin necesidad de reentrenar modelos.
3. **Citación Obligatoria:** Todas las respuestas del agente incluyen estrictamente la fuente consultada al final (ej. `*Fuente consultada: 03_caja_menor_xpertic.md*`).
